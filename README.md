# Grove P9813 pour micro:bit

DATA = P0
CLOCK = P14

Extension MakeCode pour la Grove Chainable RGB LED avec contrôleur P9813.

Test :
1. Dans « au démarrage », mettre « initialiser LED Grove P9813 ».
2. Mettre « LED verte », attendre 1 seconde, « LED éteinte », attendre 1 seconde.

Le protocole est basé sur la bibliothèque ChainableLED de Seeed Studio.
